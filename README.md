# scooter-unwritten-rules

以互動 3D 動畫介紹機車不成文規定，讓騎士看懂自己的停車方式如何影響旁邊的機車與他人。

## 初期內容

- 中柱與側柱：比較車身姿態、側向占用空間，以及鄰車進出的差異。
- 龍頭角度：比較龍頭朝正前方、向左轉與轉到底時，把手和後照鏡的空間變化。
- 後續可補充停車間距、出入口留空，以及停車後確認鄰車能否移出的情境。

## 3D 演示方向

- 提供俯視與斜側視角，支援旋轉觀察。
- 切換停車姿態與龍頭角度，播放鄰車移入、移出的動畫。
- 標示占用範圍與可能接觸的位置，說明動作對他人的影響。
- 比較應考量車款、車位寬度與地面條件，避免把單一情境當成普遍結論。
